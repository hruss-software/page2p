How the multiplayer API works (for pasted games)
The site injects a small `window.multiplayer` object into your pasted HTML which contains:
  • multiplayer.send(obj) — send a JSON-serializable object to peer(s)
  • multiplayer.onReceive(fn) — receive objects from peer(s)
  • multiplayer.playerId — your local id string
  • multiplayer.sendRaw(type, payload) — lower-level messages
